Checkm8 OTG v1.2.0 — deliverable summary
========================================

APK (in repo):
  Checkm8OTG/Checkm8OTG-debug.apk
  (same bytes as Checkm8OTG/app/build/outputs/apk/debug/app-debug.apk)

What changed in v1.2.0 (unresponsive-buttons fix):
  - Buttons now give immediate, synchronous feedback on tap (header line +
    status), before any root/binary work that could block.
  - Output is streamed LIVE line-by-line (stdout+stderr merged) into the app
    log instead of being buffered until the process exits.
  - Runs are cancellable: new Cancel button kills the child process group via
    an independent root shell, so a stuck gaster/palera1n retry loop no longer
    freezes every button for the 900s libsu timeout.
  - Explicit root pre-check: if su is not granted the log says so loudly
    instead of silently running non-root and failing on /dev/bus/usb.
  - USB pre-flight prints getenforce, the /dev/bus/usb nodes, lsusb, and
    whether an Apple VID (05ac) is visible, so a missing device is obvious.
  - Child runs detached (setsid) with exit code captured and reported.

Bundled engines (all Stored/uncompressed in APK):
  assets/gaster     — aarch64 Android NDK PIE ELF (libusb+libcrypto static)
  assets/palera1n   — palera1n-linux-arm64 v2.2 (musl-static)
  assets/checkra1n  — checkra1n-linux-arm64 (musl-static), passed via -i

Install:  adb install -r Checkm8OTG-debug.apk
Flow:     DFU iPhone -> OTG -> grant root -> Exploit (pwned DFU) and/or
          pick Rootless/Rootful -> Jailbreak (palera1n); Cancel to stop.

Support:
  gaster:    A5-A11 / T2
  palera1n:  A8-A11 / T2, iOS/iPadOS/tvOS 15-26
  NOT:       A12+
